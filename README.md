# NLP Projects

A collection of Natural Language Processing projects and labs.

## Repository Structure

- **`PlagiarismChecker/`**: A project that detects plagiarism between text pairs using a simple Feed-Forward Neural Network (MLP) and custom similarity features.
- **`SentimentAnalysis/`**: A project focused on classifying the sentiment of text data.
- **`TextProcessing/`**: Lab exercises covering fundamental text processing techniques across different sections.
